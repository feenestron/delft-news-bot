# Delft News Bot

Telegram-бот, который каждое утро собирает местные новости и анонсы мероприятий Делфта,
переводит и сокращает их на русский (через Claude API), присылает черновик модератору
и после одобрения публикует в канал.

Работает целиком на GitHub Actions — сервер не нужен.

```
06:20  GitHub Actions собирает новости и афишу
  ↓    Claude отбирает, переводит, сокращает
  ↓    черновик приходит вам в личку бота: [✅ Опубликовать] [❌ Отклонить]
  ↓    (поправить текст — ответить на черновик исправленной версией)
  →    пост уходит в канал сразу после нажатия (до 12:00), позже — в течение часа
```

## Пример поста

> **🗞 Делфт · четверг, 22 октября**
>
> **📰 События**
> • **Крупный пожар в центре удалось локализовать** — Эвакуированы жители десяти домов. [Omroep Delft]
> • …
>
> **📅 Анонсы**
> • **сб 24 окт, 20:15** · Tim Burton's Universe (Nieuwe Kerk, €25) →
> • **вс 25 окт, 11:00–17:00** · День науки в TU Delft (TU Delft Science Centre, бесплатно) →

## Настройка (один раз, ~15 минут)

### 1. Бот и канал
1. В Telegram откройте **@BotFather** → `/newbot`, придумайте имя. Сохраните **токен**.
2. Создайте публичный канал (например `@delft_test`), добавьте бота
   **администратором** с правом публикации сообщений.
3. Откройте личный чат со своим ботом и нажмите **Start** (это нужно, чтобы бот мог вам писать).

### 2. Ключ Claude API
На [console.anthropic.com](https://console.anthropic.com) создайте API-ключ и пополните баланс
(дайджест стоит порядка нескольких центов в день). Без ключа бот тоже работает,
но заголовки будут на нидерландском без перевода.

### 3. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `CHANNEL_ID` | `@имя_канала` (для закрытого канала — числовой id вида `-100…`) |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `ADMIN_CHAT_ID` | ваш числовой chat_id — см. шаг 4 |

### 4. Узнать свой chat_id
**Actions → Moderate → Run workflow**. Пока `ADMIN_CHAT_ID` не задан, бот ответит в личку:
«Ваш chat_id: 123456789». Добавьте это число в секрет `ADMIN_CHAT_ID`.

### 5. Проверка
1. **Actions → Daily digest → Run workflow**, отметьте **dry_run** — дайджест появится
   в логе, в Telegram ничего не уйдёт. Удобно проверять источники.
2. Затем запустите без dry_run — черновик придёт вам в личку.

Дальше всё работает само по расписанию.

## Модерация

* **✅ Опубликовать** — пост уходит в канал как есть.
* **❌ Отклонить** — сегодня ничего не публикуется.
* **Правка** — скопируйте текст черновика, исправьте и отправьте боту **ответом (Reply)
  на черновик**. Бот пришлёт новую версию с кнопками; форматирование и ссылки сохраняются.
* Команды: `/status`, `/publish`, `/reject`, `/help`.

До 12:00 нажатия обрабатываются сразу (утренний запуск ждёт решения), позже —
раз в час (workflow **Moderate**). Неопубликованный черновик заменяется следующим утром.

## Настройки (необязательно)

**Settings → Secrets and variables → Actions → Variables**:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DRAFT_HOUR` | `6` | час (по Амстердаму), когда готовится черновик; cron в `digest.yml` настроен на 06:23 |
| `MODERATION_UNTIL_HOUR` | `12` | до скольки утренний запуск ждёт нажатия |
| `NEWS_WINDOW_HOURS` | `30` | насколько свежими должны быть новости |
| `EVENT_HORIZON_DAYS` | `3` | на сколько дней вперёд брать анонсы |
| `MAX_NEWS` / `MAX_EVENTS` | `8` / `8` | максимум пунктов в разделах |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | модель Claude |

Если меняете `DRAFT_HOUR`, поправьте и cron в `.github/workflows/digest.yml`
(два времени UTC — для летнего и зимнего времени).

## Источники

Список — в [`sources.yaml`](sources.yaml); источник можно добавить или отключить
(`enabled: false`) без правки кода.

| Новости | Афиша |
|---|---|
| Omroep Delft (RSS) | Uit Delft (JSON API) |
| Delft op Zondag | Delft op Zondag — агенда |
| Gemeente Delft | OPEN Delft / DOK (выключен: дублирует Uit Delft) |
| Delta, TU Delft (RSS) | In Delft — Uitagenda |

Бот соблюдает `robots.txt`, представляется отдельным User-Agent и заходит на каждый
сайт один раз в день. Если источник сломался (сменили вёрстку), это видно в служебном
сообщении к черновику: «⚠️ Проблемы с источниками».

Как бот понимает, что новое:
* новости — по дате публикации и списку уже увиденных ссылок; при первом запуске
  источника всё, что уже висит на странице без даты, считается старым;
* анонсы — по дате события (из API, из ссылки или со страницы); каждое событие
  анонсируется один раз.

Состояние хранится в `state/state.json` и коммитится workflow автоматически.

## Локальный запуск

```bash
pip install -r requirements.txt
python -m bot digest --dry-run          # собрать и напечатать, ничего не отправлять
python -m unittest discover -s tests    # тесты
```

## Эксплуатация

* **Сбои.** Если запуск workflow упал, бот пришлёт модератору сообщение со ссылкой на запуск.
  Проблемы с отдельными источниками видны в служебном сообщении к черновику.
* **Пропущенный запуск.** Кроме основного утреннего запуска есть резервный (через час);
  черновик готовится, если до 9:00 его ещё не было.
* **Автоотключение расписания.** GitHub отключает cron в публичных репозиториях после 60 дней
  без активности; каждый утренний запуск заново включает оба расписания.
* **Репозиторий должен оставаться публичным**: утренний запуск ждёт решения модератора
  до `MODERATION_UNTIL_HOUR`, это несколько часов работы Actions в день. Для публичных
  репозиториев это бесплатно, для приватных быстро исчерпает бесплатный лимит —
  в этом случае поставьте `MODERATION_UNTIL_HOUR` = `DRAFT_HOUR` (нажатия будет обрабатывать
  почасовой Moderate).
* **Модель Claude.** Если Anthropic выведет модель из оборота, в служебном сообщении появится
  ошибка перевода — укажите новую модель в переменной `ANTHROPIC_MODEL`.
* **Смена канала/группы.** Добавьте бота в новый чат, отправьте там `/id@имя_бота`,
  запустите Moderate и обновите секрет `CHANNEL_ID`.
